# Champion Motel

Site institucional do **Champion Motel**, na Avenida Brasil, 19000, Vigário Geral, Rio de Janeiro/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Nota

Tipos de suíte, estrutura, valores e fotos devem ser confirmados com o motel antes da publicação oficial. Nenhum valor é informado no site.
